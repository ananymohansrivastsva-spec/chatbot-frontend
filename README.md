# 🤖 Chatbot Frontend (Streamlit)

A simple chatbot frontend built using Python and Streamlit.

## ✨ Features
- Chatbot UI
- Delete chat button
- Continue chatting (session-based)
- Date & time for each message

## 🚀 Installation

```bash
git clone https://github.com/your-username/chatbot-frontend.git
cd chatbot-frontend
pip install -r requirements.txt
streamlit run app.py
```

## 🔧 Tech Stack
- Python
- Streamlit
